# Aero-engine data

The raw aero-engine dataset used in this study is not included in this
source-code repository.

The production analysis expects ten aero-engine CSV files named:

- `aeroeng1.csv`
- `aeroeng2.csv`
- `aeroeng3.csv`
- `aeroeng4.csv`
- `aeroeng5.csv`
- `aeroeng6.csv`
- `aeroeng7.csv`
- `aeroeng8.csv`
- `aeroeng9.csv`
- `aeroeng10.csv`

The dataset is maintained separately from the public source-code repository.
A separate Zenodo data record is intended for the dataset. Access to the
files may be public or restricted depending on the applicable redistribution
permissions.

Researchers interested in obtaining access to the data may contact the
corresponding author. Any provision or redistribution of the data remains
subject to the permissions and restrictions applicable to the original
dataset.

The source-code repository contains the complete validation workflow,
analysis scripts, derived summary results, and manuscript figures required
to reproduce the computational procedure once the input data are available.

No raw aero-engine observations are tracked in this Git repository.
